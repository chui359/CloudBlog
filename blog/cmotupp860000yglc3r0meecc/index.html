前言

當 GitHub Organization 啟用了 SAML SSO（單一登入驗證）時，透過 HTTPS clone 專案時，常會遇到每次 git pull / git push / git clone 都需要重新登入的問題。

這種情況會大幅降低開發效率，因此本篇文章將整理一套 Windows 環境下 GitHub Organization Repo 使用 SSH + SSO 的完整設定方式，讓你：

  • 不再每次 Git 操作都重新登入
  • 可正常 clone / pull / push 公司 repo
  • 解決公司網路封鎖 SSH Port 22 問題
  • 解決 SSH 權限與 SSO 授權問題

通常代表公司網路封鎖 SSH Port 22。

問題 3：SSH Key 已設定，但仍無法存取 Repo

代表 SSH Key 尚未被公司組織授權。
